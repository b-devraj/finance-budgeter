# 💰 Personal Finance Budgeter with Databricks

This project is a fully automated personal finance budgeter built on **Databricks**, designed to help track, analyze, and report monthly income and spending trends. It leverages **Apache Spark**, **Delta Lake**, and **Databricks Workflows** to create a scalable and hands-free solution for personal financial management.

---

## 📌 Features

- **Automated Data Ingestion**  
  Parses and loads monthly bank and credit card statements into Delta Lake tables.

- **Spending & Income Categorization**  
  Classifies transactions by category to monitor financial habits and trends.

- **Scheduled Monthly Workflows**  
  Uses Databricks Jobs to automatically run the budgeting pipeline each month.

- **Monthly Summary Reports**  
  Outputs a clear overview of income, spending by category, savings, and month-over-month changes.

---

## ⚙️ Tech Stack

- **Databricks**
- **Apache Spark**
- **Delta Lake**
- **Databricks Workflows (Jobs)**
- **Python / PySpark**

---

## 🚀 Getting Started

1. Clone this repository to your local machine or import it into your Databricks workspace.
2. Upload your monthly bank/credit card CSVs to DBFS or cloud storage.
3. Configure the notebook paths and workflow settings to point to your data location.
4. Schedule the workflow to run monthly using Databricks Jobs.
